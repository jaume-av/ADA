# Exercicis — Streams en Java

> Tots els arxius d’entrada existeixen dins de **`Documentos/`** (provinent de `Documentos.zip`). Els programes han de crear els fitxers d’eixida indicats i tancar els fluxos amb `try-with-resources`.

---


## Streams de bytes

### Exercici 1. Còpia binària en blocs

**Entrada:** `Documentos/pi-million.txt`  
**Eixida:** `Documentos/pi-million.copy`

Copia el fitxer **sense modificar-ne cap byte** i mostra quants bytes s’han copiat.

1. Obri l’entrada i l’eixida com a fluxos de bytes.
2. Llig i escriu en blocs fins al final del fitxer.
3. Acumula el nombre de bytes copiats i mostra el total.

**Pista:** `read(byte[])` pot omplir només una part de l’array. Usa el nombre que retorna per a indicar quants bytes ha d’escriure `write(byte[], int, int)`. Encara que el fitxer acabe en `.txt`, ací el tractem com a bytes perquè volem una còpia exacta.

### Exercici 2. Estadístiques de bytes

**Entrada:** `Documentos/diccionario.txt`  
**Eixida:** resultats per consola.

Calcula el **nombre total de bytes**, el valor **mínim**, el **màxim** i la **mitjana** dels valors del fitxer, considerant cada byte com un nombre entre `0` i `255`.

1. Llig el fitxer en blocs de bytes.
2. Processa únicament les posicions omplides en cada lectura.
3. Actualitza el mínim, el màxim, la suma i el recompte.
4. Mostra els resultats al final.

**Pista:** els elements de `byte[]` tenen signe. Utilitza `Byte.toUnsignedInt(bloc[i])` per obtindre valors de `0` a `255`. El diccionari conté caràcters accentuats i permet comprovar esta conversió, encara que en este exercici no llegim les paraules com a text.

### Exercici 3. Guardar nombres en binari

**Entrada:** `Documentos/numeros.txt`  
**Eixida:** `Documentos/numeros.dat`

`numeros.txt` conté **1.000 nombres enters**, un per línia. Guarda’ls en un fitxer binari i torna a llegir-los.

1. Llig les línies de `numeros.txt` com a text.
2. Amb `DataOutputStream`, escriu primer el nombre de valors (`1.000`) i després cada nombre amb `writeInt()`.
3. Tanca els fluxos i obri `numeros.dat` amb `DataInputStream`.
4. Llig primer la quantitat de valors. Després, llig exactament eixa quantitat de nombres amb `readInt()`.
5. Mostra la quantitat llegida i els **cinc primers nombres**.

**Pistes:**

- `Integer.parseInt(linia)` transforma una línia de text en un `int`.
- El primer `readInt()` recupera la quantitat; els següents recuperen els nombres. L’ordre de lectura ha de coincidir amb el d’escriptura.
- No has d’obrir `numeros.dat` amb un lector de text: conté enters en format binari.

## Streams de caràcters

### Exercici 4. Numerar línies d’un fitxer

**Entrada:** `Documentos/frases.txt`  
**Eixida:** `Documentos/frases_numeradas.txt`

Llig les frases i guarda-les en un altre fitxer amb un número davant de cada línia:

```text
0001 | Primera frase...
0002 | Segona frase...
```

Llig i escriu **línia a línia**, indica **UTF-8** en els dos fitxers i afegeix un salt de línia després de cada frase.

**Pistes:**

- `BufferedReader.readLine()` llig una línia sense el salt final; `BufferedWriter.newLine()` permet escriure’l.
- `String.format("%04d", numero)` forma un número de quatre xifres completat amb zeros.
- Pots indicar UTF-8 amb `FileReader` i `FileWriter`, o construir els fluxos mitjançant `InputStreamReader` i `OutputStreamWriter`. Les dues opcions són vàlides.

### Exercici 5. Ordenar noms i guardar-los

**Entrada:** `Documentos/usa_personas.txt`  
**Eixida:** `Documentos/usa_personas_sorted.txt`

Llig tots els noms, ordena’ls alfabèticament **sense distingir majúscules de minúscules** i escriu-los en el fitxer d’eixida, un per línia.

1. Guarda les línies llegides en una `ArrayList<String>`.
2. Ordena la llista.
3. Escriu-ne el contingut en UTF-8, respectant els noms repetits.

**Pista:** pots ordenar amb `noms.sort(String.CASE_INSENSITIVE_ORDER)`. Per a l’escriptura pots usar `BufferedWriter` o `PrintWriter`.

### Exercici 6. Diccionari per lletra inicial

**Entrada:** `Documentos/diccionario.txt`  
**Eixides:** `Documentos/Diccionario/A.txt`, `B.txt`, …, `Z.txt`.

Crea la carpeta `Documentos/Diccionario/` i guarda en cada fitxer les paraules que comencen per la lletra corresponent.

1. Llig el diccionari com a text UTF-8, línia a línia.
2. Salta les línies buides i obtín la inicial de cada paraula en majúscula.
3. Si la inicial està entre `A` i `Z`, escriu la paraula en el fitxer corresponent, seguida d’un salt de línia.
4. Tanca correctament tots els fitxers utilitzats.

Les paraules que comencen per `Ñ`, una vocal accentuada o un signe **queden fora d’este exercici**: només es demanen els fitxers `A.txt` a `Z.txt`.

**Pistes:**

- Pots crear la carpeta amb la classe `File`, treballada en el tema anterior.
- `paraula.charAt(0)` obté la inicial i `Character.toUpperCase()` la passa a majúscula.
- Una opció senzilla és guardar les paraules en una llista i crear els fitxers d’eixida **d’un en un**. Així pots usar `try-with-resources` sense mantindre 26 escriptors oberts alhora.
