# Exercicis POJO (JSON i XML)


**Objectiu:** analitzar l’estructura dels documents i crear les classes Java que els representen. En tots els exercicis, utilitza camps privats, constructor buit, getters i setters. Quan hi haja elements repetits, utilitza `List<T>`.

De moment **no cal llegir fitxers ni utilitzar Jackson**.

## JSON

### Exercici 1. Valors simples

A partir d’aquest JSON:

```json
{
  "nom": "Ratolí sense fil",
  "quantitat": 15,
  "preu": 19.95,
  "disponible": true
}
```

Crea la classe `Producte`. Tria el tipus Java adequat per a cada camp.

### Exercici 2. Objecte dins d’un altre

A partir d’aquest JSON:

```json
{
  "marca": "Toyota",
  "model": "Corolla",
  "any": 2020,
  "motor": {
    "cilindrada": 1800,
    "combustible": "gasolina"
  }
}
```

Crea les classes `Cotxe` i `Motor` amb els camps adequats.

### Exercici 3. Llista de valors simples

A partir d’aquest JSON:

```json
{
  "ciutat": "Madrid",
  "temperatures": [19, 21, 18, 23, 20]
}
```

Crea la classe `EstacioMeteorologica` amb una llista d’enters per a les temperatures.

### Exercici 4. Llista d’objectes

A partir d’aquest JSON:

```json
{
  "codi": "C-104",
  "linies": [
    {
      "producte": "Quadern",
      "unitats": 2,
      "preuUnitari": 3.50
    },
    {
      "producte": "Bolígraf",
      "unitats": 5,
      "preuUnitari": 1.20
    }
  ]
}
```

Crea les classes necessàries per a representar la comanda. Indica quin camp ha de ser una llista i quin tipus d’objectes conté.

### Exercici 5. Objecte intern i llista d’objectes

A partir d’aquest JSON:

```json
{
  "nom": "Centre de Formació La Vall",
  "adreca": {
    "carrer": "Major",
    "numero": 12
  },
  "cursos": [
    {
      "titol": "Programació en Java",
      "hores": 40,
      "presencial": true
    },
    {
      "titol": "Bases de dades",
      "hores": 30,
      "presencial": false
    }
  ]
}
```

Decideix quantes classes necessites i crea-les. Representa correctament l’adreça i la llista de cursos.

## XML

### Exercici 6. Elements amb valors simples

A partir d’aquest XML:

```xml
<Alumne>
    <nom>Laia</nom>
    <edat>20</edat>
    <becat>true</becat>
</Alumne>
```

Crea la classe `Alumne` amb els camps i tipus adequats.

### Exercici 7. Atributs i elements

A partir d’aquest XML:

```xml
<Pellicula codi="P-12" disponible="true">
    <titol>Interstellar</titol>
    <durada>169</durada>
</Pellicula>
```

Crea la classe `Pellicula`. Representa tant les dades que apareixen com a **atributs** de l’element inicial com les que apareixen dins d’**elements**.

### Exercici 8. Element dins d’un altre

A partir d’aquest XML:

```xml
<Client>
    <nom>Carla</nom>
    <adreca>
        <carrer>La Pau</carrer>
        <numero>8</numero>
        <ciutat>Alcoi</ciutat>
    </adreca>
</Client>
```

Crea les classes necessàries per a representar el client i la seua adreça.

### Exercici 9. Elements repetits

A partir d’aquest XML:

```xml
<Biblioteca>
    <Llibre>
        <Titol>Dune</Titol>
        <Autor>Frank Herbert</Autor>
    </Llibre>
    <Llibre>
        <Titol>Neuromàntic</Titol>
        <Autor>William Gibson</Autor>
    </Llibre>
</Biblioteca>
```

Crea les classes `Biblioteca` i `Llibre` perquè puguen representar aquestes dades. Fixa’t en què hi ha diversos elements `Llibre`.

### Exercici 10. Atributs, objecte intern i llista

A partir d’aquest XML:

```xml
<Centre codi="CF-01">
    <nom>Centre de Formació La Vall</nom>
    <adreca>
        <carrer>Major</carrer>
        <numero>12</numero>
    </adreca>
    <alumnes>
        <alumne id="A1">
            <nom>Maria</nom>
            <edat>21</edat>
        </alumne>
        <alumne id="A2">
            <nom>Pere</nom>
            <edat>23</edat>
        </alumne>
    </alumnes>
</Centre>
```

Crea les classes necessàries per a representar el centre. Identifica l’atribut del centre, l’objecte que representa l’adreça i la llista d’alumnes. Cada alumne també té un atribut.

## Ampliació

### A. JSON amb una llista en l’arrel

```json
[
  {"id": 1, "nom": "Aina"},
  {"id": 2, "nom": "Pau"}
]
```

Crea la classe que representa **un element** de la llista. Indica quin tipus Java representaria el document complet.

### B. XML amb una llista dins d’un contenidor

Compara l’estructura d’aquest XML amb la de l’exercici 9:

```xml
<Biblioteca>
    <llibres>
        <Llibre>
            <Titol>Dune</Titol>
            <Autor>Frank Herbert</Autor>
        </Llibre>
        <Llibre>
            <Titol>Neuromàntic</Titol>
            <Autor>William Gibson</Autor>
        </Llibre>
    </llibres>
</Biblioteca>
```

Identifica quin element s’ha afegit per a agrupar els llibres i explica si continuaries representant els llibres amb una `List<Llibre>`.



# Casos pràctics: de JSON i XML a POJOs

En cada cas, **analitza el document i crea les classes Java que el representen**. Decideix els noms de les classes, els camps i els tipus de dades. Utilitza camps privats, constructor buit, getters i setters; pots generar aquests mètodes amb l’IDE.

Entrega cada classe pública en un fitxer `.java` diferent i acompanya el codi d’un esquema breu que mostre les relacions entre classes. **Encara no cal llegir els documents amb Jackson.**

## Cas pràctic 1. Fira de videojocs — JSON

```json
{
  "codi": "FV-26",
  "nom": "Fira de Videojocs de la Vall",
  "entradaGratuita": false,
  "organitzador": {
    "nom": "Associació Joc Jove",
    "contacte": {
      "correu": "info@jocjove.org",
      "telefon": "964123456"
    }
  },
  "categories": ["estratègia", "esports", "aventura"],
  "tornejos": [
    {
      "codi": "T-01",
      "joc": {
        "titol": "Circuit Nitro",
        "plataforma": "PC"
      },
      "places": 16,
      "quota": 5.0,
      "participants": [
        {"nom": "Marta", "edat": 20},
        {"nom": "Pau", "edat": 19}
      ]
    },
    {
      "codi": "T-02",
      "joc": {
        "titol": "Bloc Arena",
        "plataforma": "Consola"
      },
      "places": 8,
      "quota": 0.0,
      "participants": [
        {"nom": "Aina", "edat": 18},
        {"nom": "Joan", "edat": 22}
      ]
    }
  ]
}
```

**Tasques**

1. Crea tots els POJOs necessaris per a representar la fira.
2. Diferencia les llistes de valors simples de les llistes d’objectes i tria el tipus de cada camp.
3. Explica breument per què `organitzador`, `joc` i `participants` no es representen de la mateixa manera.

## Cas pràctic 2. Reserva d’hotel — XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<reserva codi="R-205" confirmada="true">
    <client>
        <nom>Neus Soler</nom>
        <contacte>
            <correu>neus@example.org</correu>
            <telefon>612345678</telefon>
        </contacte>
    </client>

    <habitacions>
        <habitacio numero="204">
            <tipus>doble</tipus>
            <preuNit>84.50</preuNit>
            <ocupants>
                <ocupant>Neus Soler</ocupant>
                <ocupant>Marc Ferrer</ocupant>
            </ocupants>
        </habitacio>
        <habitacio numero="205">
            <tipus>individual</tipus>
            <preuNit>59.00</preuNit>
            <ocupants>
                <ocupant>Aina Soler</ocupant>
            </ocupants>
        </habitacio>
    </habitacions>

    <servei>
        <nom>Esmorzar</nom>
        <preu>12.50</preu>
    </servei>
    <servei>
        <nom>Aparcament</nom>
        <preu>10.00</preu>
    </servei>
</reserva>
```

**Tasques**

1. Crea tots els POJOs necessaris per a representar la reserva.
2. Identifica quines dades apareixen com a **atributs XML** i quines apareixen com a **elements**. Assigna a totes un camp Java amb el tipus adequat.
3. Identifica els elements repetits i representa’ls amb les llistes corresponents.
4. Explica la diferència entre l’estructura de les `habitacio` i la dels `servei`, i indica com has representat els `ocupant`.
