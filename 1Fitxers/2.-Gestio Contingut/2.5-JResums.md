# Gestió d'una comanda i un magatzem

Una botiga d'informàtica guarda les seues dades en dos fitxers:

- **`comanda.json`**: conté una comanda amb els productes i les quantitats sol·licitades per un client.
- **`magatzem.xml`**: conté els productes del magatzem, els preus i les existències disponibles.

Heu de desenvolupar un programa Java que llija els dos fitxers, comprove si hi ha prou existències per a preparar la comanda i actualitze les quantitats del magatzem.

Finalment, el programa ha de guardar la comanda en un nou fitxer JSON i el magatzem actualitzat en un nou fitxer XML.

**Totes les operacions s'han de realitzar sobre objectes Java, utilitzant Jackson 3. Els documents originals no s'han de modificar.**

---

### Fitxers d'entrada

Guardeu els documents següents en la carpeta `dades/` del projecte.

* **`dades/comanda.json`**

```
{
  "numero": "C-2026-015",
  "client": {
    "nom": "Anna Martínez",
    "correu": "anna@example.com"
  },
  "data": "04-11-2026",
  "linies": [
    {
      "codi": "P01",
      "quantitat": 2
    },
    {
      "codi": "P02",
      "quantitat": 5
    },
    {
      "codi": "P03",
      "quantitat": 1
    },
    {
      "codi": "P04",
      "quantitat": 3
    }
  ]
}
```

* **`dades/magatzem.xml`**

```
<magatzem codi="M-01">
    <nom>Magatzem Informàtic La Vall</nom>
    <productes>
        <producte id="P01">
            <nom>Ratolí sense fil</nom>
            <preu>19.95</preu>
            <estoc>10</estoc>
        </producte>
        <producte id="P02">
            <nom>Teclat mecànic</nom>
            <preu>49.90</preu>
            <estoc>3</estoc>
        </producte>
        <producte id="P03">
            <nom>Monitor 24 polzades</nom>
            <preu>129.99</preu>
            <estoc>5</estoc>
        </producte>
        <producte id="P04">
            <nom>Memòria USB 64 GB</nom>
            <preu>12.50</preu>
            <estoc>3</estoc>
        </producte>
    </productes>
</magatzem>
```

Els codis dels productes permeten relacionar les línies de la comanda amb els productes del magatzem.

---

### 1. Creació dels POJOs 

Creeu els POJOs necessaris per a representar la informació dels fitxers `comanda.json` i `magatzem.xml` i permetre'n el mapeig amb Jackson 3.

La data de la comanda s'ha de representar mitjançant `LocalDate`.

### 2. Configuració de Jackson

Afegiu les anotacions de Jackson necessàries perquè es respecten els formats i les estructures dels documents.

En particular:

- La data de la comanda ha de conservar el format `dd-MM-yyyy`.
- L'arrel XML ha de ser `<magatzem>`.
- El codi del magatzem ha de ser un atribut XML.
- L'identificador de cada producte ha de ser un atribut XML anomenat `id`.
- Els productes han d'aparéixer dins de `<productes>`, cadascun amb l'element `<producte>`.

### 3. Lectura dels documents

Creeu el programa principal `GestioEstoc.java`.

#### 3.1. Llegir la comanda

Llegiu `dades/comanda.json` amb `ObjectMapper` i mostreu per pantalla:

- Número i data de la comanda.
- Nom i correu del client.
- Codi i quantitat sol·licitada de cada producte.

#### 3.2. Llegir el magatzem

Llegiu `dades/magatzem.xml` amb `XmlMapper` i mostreu per pantalla:

- Codi i nom del magatzem.
- Identificador, nom, preu i existències de cada producte.

### 4. Processament de la comanda

Recorreu les línies de la comanda en l'ordre en què apareixen.

Per a cada línia, busqueu el producte corresponent en el magatzem mitjançant el seu codi.

- **ACCEPTAT:** el producte existix i hi ha prou existències. Resteu de l'estoc les unitats sol·licitades.
- **REBUTJAT:** el producte no existix o no hi ha prou existències. L'estoc no s'ha de modificar.

Mostreu per pantalla el codi del producte, la quantitat sol·licitada i si la línia ha sigut acceptada o rebutjada.

Cada línia s'accepta o es rebutja completament. No es permeten entregues parcials.

### Resultat esperat

| Producte | Quantitat sol·licitada | Estoc inicial | Estat    | Estoc final |
| -------- | ---------------------- | ------------- | -------- | ----------- |
| P01      | 2                      | 10            | ACCEPTAT | 8           |
| P02      | 5                      | 3             | REBUTJAT | 3           |
| P03      | 1                      | 5             | ACCEPTAT | 4           |
| P04      | 3                      | 3             | ACCEPTAT | 0           |

---

### 5. Generació dels fitxers

#### 5.1. Generar `dades/comanda_copia.json`

Guardeu la comanda llegida en un nou fitxer JSON mitjançant `ObjectMapper`.

El fitxer ha de conservar totes les dades originals i el format de la data, amb una indentació adequada.

#### 5.2. Generar `dades/magatzem_nou.xml` — 1,5 punts

Guardeu el magatzem amb les existències actualitzades mitjançant `XmlMapper`.

El document ha de conservar els atributs i l'estructura XML original.

```

    <productes>
```
