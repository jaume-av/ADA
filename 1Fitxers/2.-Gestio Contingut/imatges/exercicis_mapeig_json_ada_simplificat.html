Exercicis de mapeig JSON

Reutilitza els POJOs creats a partir de JSON i utilitza ObjectMapper per a deserialitzar, consultar, modificar i serialitzar objectes Java.

  • Guarda els JSON originals dins de dades/.
  • Utilitza readValue() per a llegir els fitxers i writeValue() per a guardar els objectes modificats.
  • Consulta i modifica les dades amb els getters i setters dels POJOs.
  • Conserva els documents originals sense modificar-los.
Exercici 1 Valors simples

Producte: valors simples

Reutilitza el POJO Producte de l’exercici anterior.

  1. Guarda el document original en dades/producte.json.
  2. Llig el fitxer amb Jackson i crea un objecte Producte.
  3. Mostra el nom, la quantitat, el preu i la disponibilitat.
  4. Augmenta el preu un 10 % i la quantitat en 5 unitats.
  5. Guarda l’objecte en dades/producte_modificat.json.
Solució⌄
dades/producte.json
{
  "nom": "Ratolí sense fil",
  "quantitat": 15,
  "preu": 19.95,
  "disponible": true
}

Exercici1.java
package com.jaume.jackson;

import java.io.File;
import tools.jackson.databind.ObjectMapper;

public class Exercici1 {
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        Producte producte = mapper.readValue(
                new File("dades/producte.json"), Producte.class);

        System.out.println("Nom: " + producte.getNom());
        System.out.println("Quantitat: " + producte.getQuantitat());
        System.out.println("Preu: " + producte.getPreu());
        System.out.println("Disponible: " + producte.isDisponible());

        producte.setPreu(producte.getPreu() * 1.10);
        producte.setQuantitat(producte.getQuantitat() + 5);

        mapper.writeValue(
                new File("dades/producte_modificat.json"), producte);
    }
}
Comprovació: quantitat final de 20 unitats. El resultat matemàtic del preu és 21,945; amb double pot aparéixer una representació decimal aproximada.

Exercici 3 Llista simple

Estació meteorològica: llista de valors

Reutilitza EstacioMeteorologica amb una List<Integer>.

  1. Guarda el JSON en dades/estacio.json.
  2. Deserialitza’l en un objecte EstacioMeteorologica.
  3. Mostra la ciutat i totes les temperatures.
  4. Calcula i mostra la temperatura mitjana.
  5. Afig una temperatura de 25 graus.
  6. Guarda dades/estacio_modificada.json.
Solució⌄
dades/estacio.json
{
  "ciutat": "Madrid",

        this.temperatures = temperatures;
    }

    public void setCiutat(String ciutat) { this.ciutat = ciutat; }

Exercici3.java
package com.jaume.jackson;

import java.io.File;
import tools.jackson.databind.ObjectMapper;

public class Exercici3 {
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        EstacioMeteorologica estacio = mapper.readValue(
                new File("dades/estacio.json"), EstacioMeteorologica.class);

        System.out.println("Ciutat: " + estacio.getCiutat());
        int suma = 0;
        for (int temperatura : estacio.getTemperatures()) {
            System.out.println("Temperatura: " + temperatura);
            suma += temperatura;
        }
        double mitjana = (double) suma / estacio.getTemperatures().size();
        System.out.println("Temperatura mitjana: " + mitjana);

        estacio.getTemperatures().add(25);
        mapper.writeValue(
                new File("dades/estacio_modificada.json"), estacio);
    }
}
Comprovació: la mitjana original és 20,2 °C. La llista guardada acaba en 25.

package com.jaume.jackson;

import java.io.File;
import tools.jackson.databind.ObjectMapper;

public class Exercici4 {
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        Comanda comanda = mapper.readValue(
                new File("dades/comanda.json"), Comanda.class);

        System.out.println("Codi: " + comanda.getCodi());
        double total = 0;
        for (LiniaComanda linia : comanda.getLinies()) {
            System.out.println("Producte: " + linia.getProducte());
            System.out.println("Unitats: " + linia.getUnitats());
            System.out.println("Preu unitari: " + linia.getPreuUnitari());
            total += linia.getUnitats() * linia.getPreuUnitari();
        }
        System.out.println("Import total: " + total + " €");

        for (LiniaComanda linia : comanda.getLinies()) {
            if (linia.getProducte().equals("Quadern")) {
                linia.setUnitats(4);
            }
        }
        mapper.writeValue(
                new File("dades/comanda_modificada.json"), comanda);
    }
}
Comprovació: total inicial de 13 €; després de la modificació, el nou total seria 20 €.

Exercici 6 Anotacions

Mapeig JSON amb anotacions

Crea Empleat i utilitza les anotacions per a adaptar les propietats JSON als camps Java.

  1. Part A. Crea Empleat amb nom, departament, telefon, contrasenya, dataIncorporacio (LocalDate) i salari (double). Inclou constructors, getters i setters.
  2. Fes correspondre nom amb nom_complet, ignora la contrasenya en les dos direccions, omet els null en l’escriptura i usa el patró dd-MM-yyyy per a la data.
  3. Part B. Llig dades/empleat.json i mostra totes les propietats, inclosa la contrasenya.
  4. Canvia el salari a 2000.00 i assigna null al departament. Guarda dades/empleat_modificat.json.
  5. Part C. Canvia NON_NULL per NON_EMPTY; torna a executar i compara què passa amb telefon: "".
Solució⌄
dades/empleat.json
{
  "nom_complet": "Anna Martínez",
  "departament": "Informàtica",
  "telefon": "",
  "contrasenya": "abc123",
  "dataIncorporacio": "15-09-2024",
  "salari": 1850.50
}
Empleat.java — NON_NULL
package com.jaume.jackson;

import java.time.LocalDate;
import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.annotation.JsonIgnore;
import com.fasterxml.jackson.annotation.JsonInclude;
import com.fasterxml.jackson.annotation.JsonFormat;

@JsonInclude(JsonInclude.Include.NON_NULL)
public class Empleat {
    @JsonProperty("nom_complet")
    private String nom;
    private String departament;
    private String telefon;
    @JsonIgnore
    private String contrasenya;
    @JsonFormat(pattern = "dd-MM-yyyy")
    private LocalDate dataIncorporacio;
    private double salari;

    public Empleat() {}
    public Empleat(String nom, String departament, String telefon,
                   String contrasenya, LocalDate dataIncorporacio, double salari) {
        this.nom = nom;
        this.departament = departament;
        this.telefon = telefon;
        this.contrasenya = contrasenya;
        this.dataIncorporacio = dataIncorporacio;
        this.salari = salari;
    }

    public String getNom() { return nom; }
    public void setNom(String nom) { this.nom = nom; }
    public String getDepartament() { return departament; }
    public void setDepartament(String departament) { this.departament = departament; }
    public String getTelefon() { return telefon; }
    public void setTelefon(String telefon) { this.telefon = telefon; }
    public String getContrasenya() { return contrasenya; }
    public void setContrasenya(String contrasenya) { this.contrasenya = contrasenya; }
    public LocalDate getDataIncorporacio() { return dataIncorporacio; }
    public void setDataIncorporacio(LocalDate dataIncorporacio) {
        this.dataIncorporacio = dataIncorporacio;
    }
    public double getSalari() { return salari; }
    public void setSalari(double salari) { this.salari = salari; }
}

Contrasenya: @JsonIgnore impedix tant llegir-la com escriure-la; getContrasenya() retorna null després de deserialitzar. Si es vol acceptar en l’entrada però ocultar-la en l’eixida, es pot substituir per @JsonProperty(access = JsonProperty.Access.WRITE_ONLY). En aplicacions reals no es guarden contrasenyes en text pla.
Comprovació final

Després de cada activitat, verifica que els objectes i les llistes s'han recuperat correctament, que els canvis es reflectixen en el JSON generat i que el document d'entrada conserva el seu contingut.

Nota: els exemples utilitzen el paquet com.jaume.jackson. Si el teu projecte utilitza un altre paquet, adapta la primera línia de les classes.
