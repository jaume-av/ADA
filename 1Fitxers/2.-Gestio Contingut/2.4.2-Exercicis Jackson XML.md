## Exercicis de mapeig XML


En els exercicis anteriors heu creat els **POJOs** a partir de diferents documents XML. Ara utilitzareu **Jackson 3** per a llegir aquests documents, convertir-los en objectes Java, consultar i modificar les dades i guardar-les novament en format XML.

**Requisits generals:**

- Reutilitzeu els POJOs dels cinc exercicis anteriors, amb els constructors, getters i setters necessaris.
- Guardeu cada XML original en un fitxer dins de la carpeta `dades/`.
- Utilitzeu `XmlMapper` i `readValue()` per a deserialitzar els fitxers.
- Consulteu i modifiqueu les dades mitjançant els mètodes dels objectes Java.
- Utilitzeu `writeValue()` per a guardar els objectes modificats en nous fitxers XML.
- Afegiu les anotacions de Jackson necessàries per a conservar els atributs, els noms dels elements i l'estructura de les llistes.
- Comproveu que els fitxers originals no s'han modificat.

### Exercici 6. Alumne: elements amb valors simples

Partiu de la classe `Alumne` creada en l'exercici 6 de POJOs.

1. Guardeu l'XML original en `dades/alumne.xml`.
2. Llegiu el fitxer amb `XmlMapper` i creeu un objecte `Alumne`.
3. Mostreu el nom, l'edat i si l'alumne està becat.
4. Modifiqueu l'edat a **21 anys** i canvieu el valor de `becat` al contrari de l'actual.
5. Guardeu l'objecte modificat en `dades/alumne_modificat.xml`.

**Important:** aquest exercici es pot resoldre sense anotacions, ja que els elements XML coincidixen amb les propietats del POJO.

### Exercici 7. Pel·lícula: atributs i elements

Partiu de la classe `Pellicula` creada en l'exercici 7 de POJOs.

1. Guardeu l'XML original en `dades/pellicula.xml`.
2. Utilitzeu les anotacions necessàries perquè `codi` i `disponible` es representen com a **atributs XML**.
3. Deserialitzeu el fitxer i mostreu el codi, la disponibilitat, el títol i la durada.
4. Modifiqueu la durada a **175 minuts** i canvieu la disponibilitat a `false`.
5. Guardeu el resultat en `dades/pellicula_modificada.xml`.

**Comprovació:** el nou XML ha de conservar `codi` i `disponible` com a atributs de `<Pellicula>`, mentre que `titol` i `durada` han de continuar sent elements.

### Exercici 8. Client: objecte imbricat

Partiu de les classes `Client` i `Adreca` creades anteriorment.

1. Guardeu l'XML original en `dades/client.xml`.
2. Deserialitzeu-lo per a obtindre un objecte `Client`, que continga un objecte `Adreca`.
3. Mostreu el nom del client, el carrer, el número i la ciutat.
4. Modifiqueu el carrer a `"Sant Nicolau"` i el número a `15`.
5. Guardeu l'objecte actualitzat en `dades/client_modificat.xml`.

**Comprovació:** les dades de l'adreça han de continuar dins de l'element `<adreca>`, sense necessitat de construir manualment les etiquetes XML.

### Exercici 9. Biblioteca: elements repetits

Partiu de les classes `Biblioteca` i `Llibre` creades en l'exercici 9 de POJOs.

1. Guardeu l'XML original en `dades/biblioteca.xml`.
2. Configureu el mapeig perquè els elements `<Llibre>` es recuperen en una `List<Llibre>`, **sense cap element contenidor addicional**.
3. Deserialitzeu el fitxer i mostreu el títol i l'autor de cada llibre.
4. Mostreu el **nombre total de llibres**.
5. Afegiu un llibre nou amb les dades següents:
   - Títol: `"Fundació"`
   - Autor: `"Isaac Asimov"`
6. Guardeu la biblioteca modificada en `dades/biblioteca_modificada.xml`.

**Comprovació:** el nou XML ha de contindre tres elements `<Llibre>` directament dins de `<Biblioteca>`, sense afegir cap contenidor com `<llibres>`.

### Exercici 10. Centre de formació: atributs, objecte imbricat i llista

Partiu dels POJOs creats per a representar el centre, l'adreça i els alumnes.

1. Guardeu l'XML original en `dades/centre.xml`.
2. Afegiu les anotacions necessàries perquè:
   - `codi` siga un atribut de `<Centre>`.
   - `id` siga un atribut de cada `<alumne>`.
   - La llista d'alumnes estiga dins de `<alumnes>` i continga elements `<alumne>`.
3. Deserialitzeu el fitxer i mostreu el codi i el nom del centre, així com el carrer i el número de l'adreça.
4. Recorreu la llista d'alumnes i mostreu-ne l'identificador, el nom i l'edat.
5. Calculeu i mostreu la **mitjana d'edat** dels alumnes.
6. Modifiqueu l'edat de l'alumna amb identificador `"A1"` a `22`.
7. Afegiu un alumne nou amb les dades següents:
   - Identificador: `"A3"`
   - Nom: `"Joan"`
   - Edat: `20`
8. Guardeu el centre actualitzat en `dades/centre_modificat.xml`.

**Comprovació:** el nou XML ha de conservar els atributs `codi` i `id`, l'objecte `<adreca>` i el contenidor `<alumnes>` amb els tres elements `<alumne>`.

### Exercici 11. Mapeig XML amb anotacions de `XmlMapper`

Partiu del document XML següent:

**`dades/empresa.xml`**

```
<empresa codi="EMP-01">
    <nom>Solucions Digitals</nom>
    <seu>
        <ciutat>València</ciutat>
        <carrer>Major</carrer>
        <numero>15</numero>
    </seu>
    <treballadors>
        <treballador id="T1">
            <nom>Anna Martínez</nom>
            <salari>1850.50</salari>
        </treballador>
        <treballador id="T2">
            <nom>Pau Ferrer</nom>
            <salari>2100.00</salari>
        </treballador>
    </treballadors>
    <avis>Reunió dilluns</avis>
    <avis>Formació divendres</avis>
</empresa>
```

#### Part A. Crear els POJOs i aplicar les anotacions XML

Creeu les classes `Empresa`, `Adreca` i `Treballador` amb els atributs següents.

**Classe `Empresa`**

| Atribut Java   | Tipus               |
| -------------- | ------------------- |
| `codi`         | `String`            |
| `nom`          | `String`            |
| `adreca`       | `Adreca`            |
| `treballadors` | `List<Treballador>` |
| `avisos`       | `List<String>`      |

**Classe `Adreca`**

| Atribut Java | Tipus    |
| ------------ | -------- |
| `ciutat`     | `String` |
| `carrer`     | `String` |
| `numero`     | `int`    |

**Classe `Treballador`**

| Atribut Java | Tipus    |
| ------------ | -------- |
| `id`         | `String` |
| `nom`        | `String` |
| `salari`     | `double` |

Afegiu a totes les classes el constructor buit, un constructor amb tots els atributs, els getters i els setters.

Utilitzeu les anotacions XML de Jackson necessàries perquè:

1. L'element arrel del document generat siga `<empresa>`, encara que la classe Java es diga `Empresa`.
2. El camp `codi` de l'empresa i el camp `id` dels treballadors es representen com a **atributs XML**.
3. L'atribut Java `adreca` es corresponga amb l'element XML `<seu>`.
4. La llista `treballadors` estiga dins de l'element `<treballadors>` i cada objecte es represente amb l'element `<treballador>`.
5. La llista Java `avisos` es represente mitjançant elements `<avis>` directament dins de `<empresa>`, **sense un element contenidor**.

#### Part B. Llegir i modificar l'XML

Creeu el programa `Exercici11.java` i realitzeu les operacions següents:

1. Llegiu `dades/empresa.xml` amb `XmlMapper` i obteniu un objecte `Empresa`.
2. Mostreu el codi i el nom de l'empresa.
3. Mostreu la ciutat, el carrer i el número de l'adreça.
4. Recorreu la llista de treballadors i mostreu-ne l'identificador, el nom i el salari.
5. Recorreu i mostreu tots els avisos.
6. Modifiqueu el salari de la treballadora amb identificador `"T1"` a `2000.00`.
7. Canvieu el carrer de la seu a `"Colom"`.
8. Afegiu un treballador nou amb les dades següents:
   - Identificador: `"T3"`
   - Nom: `"Joan Soler"`
   - Salari: `1750.00`
9. Afegiu l'avís `"Revisió mensual"`.
10. Guardeu l'objecte modificat en `dades/empresa_modificada.xml`.

#### Part C. Comprovar les anotacions XML

Obriu el fitxer `empresa_modificada.xml` generat i comproveu que:

1. L'element arrel continua sent `<empresa>`.
2. `codi` i `id` continuen sent atributs, no subelements.
3. Les dades de l'adreça apareixen dins de `<seu>`, no de `<adreca>`.
4. Els tres treballadors estan dins de `<treballadors>`, representats cadascun amb `<treballador>`.
5. Els tres avisos apareixen directament dins de `<empresa>` com a elements `<avis>`, sense un contenidor `<avisos>`.

**Comprovació final:** torneu a llegir `dades/empresa_modificada.xml` amb `XmlMapper` i comproveu que els valors modificats i els nous elements s'han recuperat correctament.

> **Important:** no modifiqueu manualment l'estructura de l'XML ni construïu etiquetes concatenant cadenes. Les diferències entre els noms Java i XML, els atributs i l'estructura de les llistes s'han de resoldre amb les anotacions de Jackson XML.
