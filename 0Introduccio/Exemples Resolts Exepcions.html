1 Exercici

Entrada d’un enter i InputMismatchException

Excepció: InputMismatchException Classe: Scanner nextInt()
Implementa un programa que demane a l’usuari un valor enter A utilitzant un nextInt() (de Scanner) i després mostre per pantalla el missatge “Valor introduït: …”.
S’haurà de tractar l’excepció InputMismatchException que llança nextInt() quan no s’introduïx un enter vàlid. En tal cas es mostrarà el missatge “Valor introduït incorrecte”.
Veure solució 
package ud10_ejercicio1;

import java.util.*; // imports genèrics (igual que en la teua versió)

public class UD10_Ejercicio1 {

    public static void main(String[] args) {

        Scanner in = new Scanner(System.in); // lector de teclat (no tanquem System.in)

        int A;        // ací guardarem l'enter introduït

        try
        {
            System.out.print("Introdueix un número enter: ");
            A = in.nextInt(); // pot llançar InputMismatchException si no s'introduïx un enter

            // Si arribem ací, la lectura ha sigut correcta
            System.out.println("Valor introduït: " + A);

        }
        catch(InputMismatchException e)
        {
            // Missatge requerit quan l'entrada no és un enter vàlid
            System.out.println("Valor introduït incorrecte");
            // Es manté printStackTrace() com en la teua versió original
            e.printStackTrace();
        }

        // El programa continua encara que s'haja produït l'excepció
        System.out.println("Fi del programa");

    }

}
2 Exercici

Divisió A/B i tractament independent d’excepcions

Excepció: InputMismatchException Excepció: ArithmeticException Scanner.nextInt()
Implementa un programa que demane dos valors int A i B utilitzant un nextInt() (de Scanner), calcule A/B i mostre el resultat per pantalla.
S’hauran de tractar de manera independent les dues possibles excepcions, InputMismatchException i ArithmeticException, mostrant en cada cas un missatge d’error diferent.
Veure solució 
package ud10_ejercicio2;

import java.util.*; // imports genèrics

public class UD10_Ejercicio2 {

    public static void main(String[] args)
    {
        Scanner in = new Scanner(System.in); // lector d'entrada

        int A,B, result;       // variables per als operands i el resultat

        try
        {
            System.out.println("Introdueix el numerador: ");
            A = in.nextInt(); // pot llançar InputMismatchException

            System.out.println("Introdueix el denominador: ");
            B = in.nextInt(); // pot llançar InputMismatchException

            result = A / B;   // pot llançar ArithmeticException si B == 0

            System.out.println(A + " / " + B + " = " + result); // eixida si tot és correcte

        }
        catch (InputMismatchException e)
        {
            System.out.println("Valor introduït incorrecte"); // cas de dades no enteres
            e.printStackTrace();             // es manté com en la teua versió
        }
        catch (ArithmeticException e)
        {
            System.out.println("Divisió entre zero: " + e); // missatge específic per /0
            e.printStackTrace();
        }

        System.out.println("Fi del programa"); // final del flux
    }
}
3 Exercici

Omplir un vector double[5] demanant valors

Excepció: InputMismatchException Array double[5]
Implementa un programa que cree un vector tipus double de mida 5 i després, utilitzant un bucle, demane cinc valors per teclat i els introduïsca en el vector.
Hauràs de gestionar la/les possibles excepcions i continuar demanant valors fins omplir completament el vector.
Veure solució 
package ud10_ejercicio3;

import java.util.*; // imports genèrics

public class UD10_Ejercicio3 {

    public static void main(String[] args) {

        Scanner in = new Scanner(System.in); // lector d'entrada

        double[] vector = new double[5];     // vector de 5 posicions

        // Recorrem tot el vector per a omplir-lo
        for(int i = 0; i < vector.length; i++)
        {
            try
            {
                System.out.println("Introdueix el valor de la posició " + i);
                vector[i] = in.nextDouble(); // pot llançar InputMismatchException si no és double
            }
            catch(InputMismatchException e)
            {
                System.out.println("Valor introduït incorrecte. Torna a introduir el valor...");
                e.printStackTrace();
                in.nextLine(); // netegem el buffer per a descartar l'entrada incorrecta
                i--;           // tornem a intentar la mateixa posició
            }
        }

        mostrarVector(vector); // mostrem el contingut del vector

    }

    // Mètode d'ajuda per a imprimir el vector (mateix estil que l'original)
    public static void mostrarVector(double[] v)
    {
       System.out.print("Dades del vector [ ");

        for(int j = 0; j < v.length; j++)
        {
            System.out.print(v[j] + ", ");
        }

        System.out.println("\b\b ]"); // xicotet truc per a llevar la coma i l'espai final
    }

}
4 Exercici

Vector d’enters aleatori i consulta per posició fins a negatiu

Excepció: InputMismatchException Excepció: ArrayIndexOutOfBoundsException Array int[N]
Implementa un programa que cree un vector d’enters de mida N (nombre aleatori entre 1 i 100) amb valors aleatoris entre 1 i 10.
Després es preguntarà a l’usuari quina posició del vector vol mostrar per pantalla, repetint-se una i una altra vegada fins que s’introduïsca un valor negatiu. Gestiona totes les possibles excepcions.
Veure solució 
package ud10_ejercicio4;

import java.util.*; // imports genèrics

public class UD10_Ejercicio4 {

    public static void main(String[] args) {

        Scanner in = new Scanner (System.in); // lector

        int N = (int)(Math.random() * 100 + 1); // mida aleatòria 1..100
        int[] vector = new int[N];

        // Omplim el vector amb valors 1..10
        for(int i = 0; i < N; i++)
        {
            vector[i] = (int)(Math.random() * 10 + 1);
        }

        int valor = 0; // posició a consultar

        do{
            try
            {
                System.out.println("Introdueix la posició del vector per a mostrar: (número negatiu per eixir)");
                valor = in.nextInt(); // pot llançar InputMismatchException

                // ✅ ÚNIC CANVI DEMANAT:
                // Comprovació prèvia del negatiu ABANS d'accedir al vector.
                // Si és negatiu, NO accedim i deixem que el do-while tanque per la condició.
                if (valor >= 0) {
                    System.out.println("Valor en el vector: " + vector[valor]);  // pot llançar ArrayIndexOutOfBoundsException
                    in.nextLine();                // netegem buffer després de llegir l'enter
                }

            }
            catch(InputMismatchException e)
            {
                System.out.println("Valor introduït incorrecte");
                in.nextLine();                // descartem el token no vàlid
            }
            catch(ArrayIndexOutOfBoundsException e)
            {
                if(valor >= 0)
                {
                    System.out.println("Posició fora dels límits del vector");
                }
            }

        } while(valor >= 0); // si és negatiu, el bucle finalitza

        System.out.println("Eixida del programa");

    }
}
