Exercici 1 — Llançament i captura d'excepcions

Completa els mètodes imprimePositivo() i imprimeNegativo() del programa següent.

  • imprimePositivo(): si el número és positiu o zero, el mostra per pantalla. Si és negatiu, llança una excepció amb el missatge «El número introducido debe ser mayor o igual a 0.»
  • imprimeNegativo(): si el número és negatiu, el mostra per pantalla. Si és positiu o zero, llança una excepció amb el missatge «El número debe ser menor a 0».
import java.util.InputMismatchException;
import java.util.Scanner;

public class Ejercicio1 {

    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        try {
            System.out.print("Introduce un número positivo\n");
            imprimePositivo(teclado.nextInt());

            System.out.print("Introduce un número negativo\n");
            imprimeNegativo(teclado.nextInt());

        } catch (InputMismatchException e) {
            e.printStackTrace();

        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    // Completa els dos mètodes
}
Veure solució 
public static void imprimePositivo(int p) throws Exception {
    if (p < 0) {
        throw new Exception(
            "El número introducido debe ser mayor o igual a 0."
        );
    }

    System.out.println(p);
}

public static void imprimeNegativo(int p) throws Exception {
    if (p >= 0) {
        throw new Exception("El número debe ser menor a 0");
    }

    System.out.println(p);
}

Exercici 2 — Flux d'execució: `try`, `catch` i `finally`

Observa el programa següent. Substitueix el comentari // INSTRUCCIÓN per cadascuna de les instruccions indicades i escriu exactament què mostrarà el programa per pantalla en cada cas.

public class Ejercicio2 {

    private static int metodo() {
        int valor = 0;

        try {
            valor = valor + 1;

            // INSTRUCCIÓN

            valor = valor + 1;
            System.out.println("Valor al final del Try: " + valor);

        } catch (NumberFormatException e) {
            valor = valor + Integer.parseInt("42");
            System.out.println("Valor al final del catch: " + valor);

        } finally {
            valor = valor + 1;
            System.out.println("Valor al final del finally: " + valor);
        }

        valor = valor + 1;
        System.out.println("Valor antes del return: " + valor);

        return valor;
    }

    public static void main(String[] args) {
        try {
            System.out.println(metodo());

        } catch (Exception e) {
            System.err.println("Excepcion en metodo()");
        }
    }
}

Cas A

valor = valor + Integer.parseInt("22");

Cas B

valor = valor + Integer.parseInt("W");
Veure solució

Cas A

Integer.parseInt("22") retorna 22, per tant no es produeix cap excepció.

Valor al final del Try: 24 Valor al final del finally: 25 Valor antes del return: 26 26

Cas B

Integer.parseInt("W") llança una NumberFormatException. L'execució abandona el try i continua en el catch.

Valor al final del catch: 43 Valor al final del finally: 44 Valor antes del return: 45 45

Exercici 3 — Excepció pròpia

Donada la classe següent, crea una nova classe ExcepcioPropia perquè el programa funcione i mostre l'eixida indicada.

public class MainExcepcions {

    public static void main(String[] args) {

        try {
            metode(1);
            System.out.println("\n ******** ");
            metode(20);

        } catch (ExcepcioPropia expropia) {
            System.out.println(
                "Capturant l'excepció " + expropia
            );
        }
    }

    static void metode(int n) throws ExcepcioPropia {

        System.out.println(
            " Estic cridant al mètode amb el valor: "
            + n + " metode(" + n + ")"
        );

        if (n > 10)
            throw new ExcepcioPropia(n);

        System.out.println("Finalització Normal!!! ");
    }
}

Eixida esperada:

Estic cridant al mètode amb el valor: 1 metode(1) Finalització Normal!!! ******** Estic cridant al mètode amb el valor: 20 metode(20) Capturant l'excepció Excepció Pròpia[20]
Veure solució 
public class ExcepcioPropia extends Exception {

    private int numero;

    public ExcepcioPropia(int numero) {
        this.numero = numero;
    }

    @Override
    public String toString() {
        return "Excepció Pròpia[" + this.numero + "]";
    }
}
